# Glossary

- **repo** — a project folder tracked by Git and hosted on GitHub. Holds every version of every file.
- **commit** — a saved snapshot of changes, with a short message describing what changed.
- **push** — send your local commits up to GitHub so they're online.
- **pull** — bring commits down from GitHub to your local copy.
- **branch** — a parallel copy of the repo you can experiment on without touching main. Merges back when the experiment works.
- **cell** — an area where you could run a block of code in.
- **runtime** — the Python engine running on Colab's computer that runs your code and keeps your variables in memory; restarting it wipes them
- **!pip** — a tool that can install and manage python libraries
- **%timeit** — a tool that can measure how long code takes to run
